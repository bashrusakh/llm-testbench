How to test variants:

Layout variants (A1-A3): Each has its own HTML file. To serve via the existing server, temporarily update INDEX_HTML in python/server.py to point to the desired variant, e.g. INDEX_HTML = PROJECT_ROOT / "index-a1.html". Or add a route for each variant.

Design channels (D4-D6): Already wired in the A1-A3 HTML files (buttons 4-6 in the channel switcher). To add them to the original index.html, add <link rel="stylesheet" href="/static/variants/channels-d456.css"> to the head and add channel buttons 4-6 to the switcher.

Visual styles (C1-C3): Add a stylesheet link and set data-style="c1" on the <html> element. Styles layer on top of channels — you can combine, e.g., channel D4 + style C2.

Combination matrix: Layout (A1/A2/A3) x Channel (v1-v6) x Style (C1-C3) = 54 possible combinations.
