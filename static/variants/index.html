How to test variants:

Layout variants (V1-V4): Each is a separate HTML file served at /static/index-vN-*.html. Switch via the layout nav inside any variant, or open directly.

Design channels (D4-D6): Add <link rel="stylesheet" href="/static/variants/channels-d456.css"> to the page head and add channel buttons 4-6 to the switcher.

Visual styles (C1-C3): Add a stylesheet link and set data-style="c1" on the <html> element. Styles layer on top of channels — you can combine, e.g., channel D4 + style C2.
